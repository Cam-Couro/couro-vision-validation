4. The synthetic pipeline — why it changes everything

Until tonight, every accuracy lift required either (a) more compute on existing data or (b) external data collection ($2K–$10K + weeks). The synthetic AMASS-style pipeline (Agent C) creates a third path:

Take any motion from a free mocap library (CMU MoCap, AMASS public subset, CC-BY AIST++). Render the body at any camera angle including rear. Output Halpe-26 keypoints + perfect ground-truth joint angles. Use as additional training data.

This means rear-view, left-side, right-oblique, etc. — every angle gets unlimited training data. The synthetic data has perfect labels (no Vicon error budget), so it's actually higher-quality GT than the real data we currently train against.

Expected impact (from Agent C's plan + standard "synthetic + real" results in the pose-estimation literature): +0.05 to +0.15 r on data-limited slots — especially ankle and rear-view metrics once we add them.

Implementation cost: ~6–9 engineering days. No external dependencies, no licensing wall.
